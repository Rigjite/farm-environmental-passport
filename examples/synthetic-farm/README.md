# Synthetic farm — input folder and generated passport (since v0.3.8)

**SYNTHETIC.** The farm of the worked examples, in the input format of `references/input-format.md`. Every laboratory value is invented and labelled as such; it is copied unchanged from the PFAS example (`../FARM-PFAS-SIMULATION-2026-10-31-r7.en.md`, §3–4) and equals `tests/fixtures/sim1_pfas.json` (test T36). Where the example gives no sampling date or method, the cell says `not stated`; the laboratory is `synthetic`. No real coordinates.

| File | What it is |
|---|---|
| `farm.json` | the farm, its eight objects, the four dose scenarios of the example, the profile, coverage and pixel-fit objects of the indicator selection |
| `measurements.csv` | 15 measured results and 2 model ranges, one per row |
| `passport.json` | generated by `python3 scripts/demo.py` — statuses, flags, dose, indicator selection, work plan, gap registry, run record |
| `answer-card.md` | generated from `passport.json` — changes no number |

Regenerate: `python3 scripts/demo.py --date 2026-11-10`. Check that the committed outputs equal a fresh run: `python3 scripts/demo.py --check` (test T39).

Module 1 (PFAS) only: the Module 2–3 series in the water example give quarters and months without a year, and a dated input cannot be written without inventing the year.
